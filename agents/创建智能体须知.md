# 创建智能体须知

## ⚠️ 首次使用必读

程序启动时会自动加载 `agents/global.txt` 作为全局智能体。

**如果 `global.txt` 不存在或关键字段为空，程序将无法启动。**

请先确保 `global.txt` 中至少配置了以下字段：
- `[服务商]` 或 `[API地址]`
- `[API Key]` 或 `[API Key 文件]`
- `[模型]`

其他智能体留空的字段会自动继承 `global.txt` 的配置。

---

## 文件位置

所有智能体配置文件放在 `agents/` 目录下，文件名任意，扩展名必须是 `.txt`。

启动时程序会自动扫描该目录下所有 `.txt` 文件并加载。

> 注意：除 `global.txt` 外的 `.txt` 文件已通过 `.gitignore` 忽略，不会提交到仓库。每个用户可自由创建自己的智能体而不影响他人。

---

## 配置格式

每个 `.txt` 文件就是一个智能体。格式为 `[字段名]` 后面紧跟内容，一个字段占一行或多行。

**global.txt 示例（全局配置）：**

```
[名称]
DeepSeek
[标识名]
global
[系统提示词]
[服务商]
deepseek
[API地址]
[API Key 文件]
/home/sti/apikey.txt
[API Key]
[模型]
deepseek-chat
[温度]
0.7
[可用工具]
read_file, edit_file, run_command, list_dir, search_files, call_agent
[可被调用]
否
[何时调用]
```

**普通智能体示例：**

```
[名称]
翻译助手
[标识名]
translator
[系统提示词]
你是一个专业的中英翻译，用户发中文你翻译成英文，发英文你翻译成中文。
[服务商]
[API地址]
[API Key 文件]
[API Key]
[模型]
[温度]
0.3
[可用工具]
[可被调用]
否
[何时调用]
```

---

## 字段说明

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| `[名称]` | 推荐 | 显示名称，如"翻译助手"、"代码审查员" |
| `[标识名]` | **必填** | 唯一 ID，用于 `@xxx` 切换，只能用英文、数字、短横线。`global` 为全局保留标识名 |
| `[系统提示词]` | 可选 | 定义角色和行为，支持多行。留空=不设定角色 |
| `[服务商]` | 可选 | 留空=继承全局。可填：deepseek、openai、moonshot、zhipu、qwen |
| `[API地址]` | 可选 | 留空=根据服务商自动匹配。也可手动填写完整地址 |
| `[API Key 文件]` | 可选 | 存放 API Key 的文件路径，程序启动时自动读取 |
| `[API Key]` | 可选 | 直接填写 API Key。优先级高于 `[API Key 文件]`。留空=继承全局 |
| `[模型]` | 可选 | 留空=继承全局模型。可填具体模型名如 deepseek-chat、gpt-4o |
| `[温度]` | 可选 | 留空=继承全局。范围 0.0~2.0，越低越严谨，越高越随机 |
| `[可用工具]` | 可选 | 留空=拥有全部工具。逗号分隔工具名限制权限 |
| `[可被调用]` | 可选 | 是/否。设为"是"后可被其他智能体通过 call_agent 调用 |
| `[何时调用]` | 可选 | 描述该智能体的适用场景，供路由和其他智能体判断何时调用 |

---

## 继承规则

其他智能体的空字段会自动从 `global.txt` 继承：

| 字段 | 留空时的行为 |
|------|-------------|
| 服务商/API地址 | 使用 global 的 API 地址 |
| API Key/API Key 文件 | 使用 global 的 API Key |
| 模型 | 使用 global 的模型 |
| 温度 | 使用 global 的温度 |
| 可用工具 | 拥有全部工具（不是继承 global） |

---

## 格式规则

1. 每个字段以 `[字段名]` 开头，下一行开始是内容
2. 空行不影响解析，可以加空行让文件更清晰，也可以不加
3. `[系统提示词]` 支持多行内容，直到遇到下一个 `[xxx]` 为止
4. 留空某个字段时，直接在 `[字段名]` 后面不写任何内容即可
5. 文件编码必须是 UTF-8
6. 文件名不影响索引，系统按 `[标识名]` 识别智能体

---

## 可用工具列表

| 工具名 | 功能 |
|--------|------|
| `read_file` | 读取文件内容 |
| `edit_file` | 编辑文件（写入/创建/覆盖/删除） |
| `run_command` | 执行终端命令 |
| `list_dir` | 列出目录结构（支持过滤隐藏文件） |
| `search_files` | 在文件中搜索文本（支持过滤隐藏文件） |
| `call_agent` | 调用其他智能体执行子任务 |
| `ask_user` | 主动向用户提问确认 |
| `get_diff` | 查看本次会话中 AI 对文件的改动记录 |

**权限控制示例：**
- 全部工具：`read_file, edit_file, run_command, list_dir, search_files, call_agent`
- 只读权限：`read_file, search_files, list_dir`
- 只写代码：`read_file, edit_file, list_dir`

> 注意：`get_diff` 工具在任何权限等级下都可用（包括权限0），无需显式添加到 `[可用工具]` 中。

---

## 权限等级

`config.txt` 中的 `[权限]` 字段控制全局工具权限：

| 等级 | 说明 |
|------|------|
| 0 | 仅聊天，不允许使用任何工具（get_diff 除外） |
| 1 | 只读（read_file、list_dir、search_files、ask_user） |
| 2 | 读写，文件修改和命令执行需用户确认 |
| 3 | 完全自动，所有工具无需确认（默认） |

权限等级会影响所有智能体。即使智能体配置了 `[可用工具]`，也不能超出全局权限限制。

## 温度参考

| 值 | 效果 | 适合场景 |
|----|------|----------|
| 0.0 | 几乎固定输出 | 数据提取、格式转换 |
| 0.3 | 稳定，偶有变化 | 代码审查、翻译 |
| 0.7 | 平衡（默认） | 日常对话、编码 |
| 1.0 | 较随机，创意多 | 写文章、头脑风暴 |
| 1.5+ | 非常随机 | 极端创意（谨慎使用） |

## 调用方法

启动程序后，在命令行中：

| 操作 | 命令 |
|------|------|
| 查看所有智能体 | `/agents` |
| 切换到某个智能体 | `@标识名`（如 `@coder`） |
| 切换并立即提问 | `@标识名 你的问题`（如 `@coder 写个排序函数`） |
| 回到全局智能体 | `@global` |
| 清空当前记忆 | `/clear` |
| 退出 | `/exit` |

**切换后输入提示符会变化：**

```
[1] 你: 使用全局智能体对话
[2] 你@coder: 已切换到开发工程师
[3] 你@code-reviewer: 已切换到代码审查员
```

每个智能体有独立的对话记忆，切换不会丢失之前的对话。`/clear` 只清空当前智能体的记忆。

## 示例：创建一个新智能体

假设你想创建一个"英语老师"智能体：

1. 在 `agents/` 目录下新建 `english-teacher.txt`
2. 填入以下内容：

```
[名称]
英语老师
[标识名]
english-teacher
[系统提示词]
你是一位耐心的英语老师。用户发送中文时，你帮助翻译并讲解语法。
用户发送英文时，你纠正语法错误并解释。
请用简洁易懂的方式教学。
[服务商]
[API地址]
[API Key 文件]
[API Key]
[模型]
[温度]
0.5
[可用工具]
[可被调用]
否
[何时调用]
```

3. 重新启动程序或输入 `/reload`，然后输入 `@english-teacher` 即可使用。

注意这里 `[可用工具]` 留空表示不给任何工具——英语老师不需要操作文件。
服务商、API地址、API Key、模型留空则自动继承 global.txt 的全局配置。
